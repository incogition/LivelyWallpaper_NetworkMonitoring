# 📟 X-PacketRay Scanner // Professional Edition

> **"Visibility is the first line of defense."**
> **X-PacketRay**는 미래지향적인 사이버 보안 인터페이스를 테마로 한 **Lively Wallpaper** 전용 라이브 배경화면입니다. 단순한 시각 효과를 넘어, 실제 시스템 리소스와 연동된 대시보드를 통해 업무 몰입감을 극대화합니다.

---

## ✨ Key Features (핵심 기능)

이 프로젝트는 보안 관제 센터(SOC)의 핵심 요소를 데스크탑 환경에 녹여냈습니다.

* **⚡ 실시간 DPI 스트림:** TCP, UDP, TLS 1.3 등 주요 프로토콜의 패킷 흐름을 시뮬레이션하여 실시간 네트워크 활동을 시각화합니다.
* **📊 하드웨어 리소스 연동:** Lively API를 통해 실제 PC의 CPU 및 RAM 사용량을 대시보드 게이지에 실시간으로 반영합니다.
* **🛡️ 지능형 위협 탐지 알림:** SQL Injection, Brute Force 등 비정상 패턴 감지 시 화면 전체에 시각적 경고(Flash Red)를 발생시킵니다.
* **🖥️ 멀티 뷰 아키텍처:** 대시보드, 트래픽 분석, 위협 로그, 시스템 진단 등 4가지 전문화된 화면 전환 기능을 제공합니다.
* **🚀 시네마틱 부팅 시퀀스:** 인프라 무결성 검사 로직이 포함된 몰입감 있는 시스템 시작 연출을 지원합니다.

---

## 🛠 실무 활용을 위한 커스터마이징 가이드

업무 환경이나 특정 프로젝트 대상을 모니터링하기 위해 소스 코드에서 수정해야 할 핵심 위치입니다.

### 1. 하드웨어 및 프로세스 모니터링 (`updateSystemData`)

실제 회사에서 사용하는 서버나 특정 소프트웨어의 리소스 점유율을 시뮬레이션하거나 이름을 변경할 때 수정합니다.

* **수정 포인트:** `TopProcess` 배열 내의 `Name`, `Cpu`, `Ram` 객체 값
* **활용 예시:** `ntopng`나 `k3s-server` 대신 실제 관리 중인 서비스 명칭(예: `ERP-DB`, `Gateway-Filter`)으로 변경하여 관제 현장감을 높일 수 있습니다.

### 2. 네트워크 프로토콜 및 타겟 설정 (`protocols`)

분석하고자 하는 특정 네트워크 서비스의 포트와 명칭을 설정합니다.

* **수정 포인트:** `const protocols` 배열
* **활용 예시:** 보안 장비에서 주로 보는 `SSH(22)`, `FTP(21)` 혹은 사내 특화 프로토콜을 추가하여 패킷 스트림의 다양성을 확보합니다.

### 3. 트래픽 소스 및 위협 시나리오 (`createPacket`)

비인가 장비 탐지나 특정 대역폭 트래픽을 감시하는 시나리오를 설정할 때 중요합니다.

* **수정 포인트:** `src`(출발지 IP), `dst`(목적지 IP), `isThreat`(위협 발생 확률)
* **활용 예시:** `src`에 실제 회사 내부망 대역폭(예: `192.168.x.x`)을 설정하거나, `isThreat` 로직을 수정하여 특정 조건에서 경고가 발생하도록 커스텀할 수 있습니다.

## 📝 설정 요약 가이드 (Quick Config)

| 구분 | 소스 코드 위치 | 수정 대상 및 내용 |
| --- | --- | --- |
| **시스템 테마** | `:root` (CSS) | 배경색, 네온 강조색(Cyan), 위협 경고색(Red) |
| **인프라 진단** | `const bootLines` | 부팅 시 출력되는 장비 체크리스트 명칭 (Cisco, NVMe 등) |
| **리소스 관리** | `updateSystemData()` | 시뮬레이션할 기본 CPU/RAM 값 및 프로세스 리스트 |
| **네트워크 분석** | `createPacket()` | 패킷 로그에 표시될 IP 주소 대역 및 위협 탐지 빈도 |

## ⚙️ Installation (설치 방법)

1. **Lively Wallpaper**를 설치 및 실행합니다.
2. 이 저장소의 파일을 다운로드한 후 `index.html`을 Lively 라이브러리에 드래그 앤 드롭합니다.
3. Lively 설정에서 **'시스템 정보(System Information)'** 접근 권한을 허용하면 실제 하드웨어 데이터와 동기화됩니다.
